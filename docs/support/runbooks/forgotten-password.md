# Forgotten password

**Symptom.** "I can't sign in." Or: "The owner forgot the password."

**Confirm.** Ask whose password it is:
- A cashier's or another staff member's: any administrator resets it from Staff. This is not a support case.
- An owner's, with another administrator in the shop: that person resets it from Staff.
- The only administrator's: use the recovery code, below.

**Fix with the recovery code.**
1. On the sign-in screen, press **Forgot password?**
2. Type the recovery code from the paper made when the shop was set up, the username (usually `admin`) and a new password.
3. Using the code makes a new one. The screen shows it once, so write it down and keep it away from the till.
4. The code is the shop's, not the machine's. It works on any till of the shop.

**Messages.**

| Message | What it means |
|---|---|
| *That is not the recovery code.* | It was mistyped, or a newer code was made and the paper is the old one. |
| *This shop has no recovery code.* | It was never made, and nobody else is an administrator. See below. |
| *There is no account switched on with that username.* | The username is wrong. Try `admin`, or the owner's name. |

**No code and no other administrator.** There is no way in at the counter, by design. This is a supervised hand repair over remote help: prove the owner is the owner first (the registered phone on the portal), then take a backup, then reset the hash by hand. Write it down: it is the case for a repair pack.

**Prevent.** At install, the checklist asks for the recovery code to be written down. Ask about it on every first call.
